# V7.5 Feature Map

| Feature | User input dependency | Output |
|---|---|---|
| Digital Twin | Candidate graph + requirements | Scenario state, metric delta, affected requirements, adaptation |
| What-If Lab | Scenario + intensity | Before/after simulation and mitigation |
| Delivery Lab | Selected architecture components | Terraform + Kubernetes + validation loop |
| Explainability | Requirement records + mappings | Requirement → driver → component evidence |
| UML | Functional requirements + candidate | Use Case, Class and Sequence diagrams |
| PDF | Stored completed analysis | Review-ready PDF decision record |

The UI does not use a fixed hospital/e-commerce architecture as the Digital Twin or UML source. The scenario catalogue contains generic failure modes, but their relevance, anchor, simulated impact and proposed adaptation are computed against the submitted requirement profile and selected candidate.
