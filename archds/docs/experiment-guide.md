# Experiment Guide

1. Load a built-in scenario or enter a controlled requirement set.
2. Record candidate count, priority weights and iteration limit.
3. Run the proposed pipeline.
4. Record final score, coverage, critical findings, convergence iteration, diversity and runtime.
5. Repeat with the baseline or ablation condition.
6. Export the stored JSON result for statistical analysis.

Recommended thesis scenarios: small low-budget CRUD, high-scale real-time platform, security/audit-heavy financial platform, healthcare monitoring and IoT telemetry.
