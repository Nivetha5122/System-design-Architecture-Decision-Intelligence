# ARCHDS V7.4 — Research Product Upgrade

## Major additions

### Requirement-grounded Digital Twin
- Reconstructs the selected architecture from the generated component graph.
- Derives a scenario catalog from the submitted requirements and architectural drivers.
- Supports workload surge, component failure, latency pressure, regional outage and security pressure when justified by the input.
- Runs an analytical simulation with component health/load, propagation, requirement impact, adaptation proposals and a timeline.
- Explicitly labels the twin as an analytical simulation rather than a production load/chaos test.

### Competitive multi-agent debate
- Performance advocate, reliability/security advocate and cost/complexity advocate challenge leading candidates.
- An arbitrator records the final evidence-backed position.
- Debate evidence is included in the architecture report.

### Research UI simplification
- Main architecture workspace reduced to seven decision-focused tabs:
  Overview, Requirements, Competition, UML, Explainability, Digital Twin, Decision.
- Redundant research/optimization/framework/agent pages are no longer exposed as competing primary tabs; their evidence remains available through the core views and report.

### Explainability
- Requirement labels are human-readable.
- Evidence chain explicitly shows submitted requirement → architectural driver → mapped component(s).
- Explanations are regenerated for the current analysis rather than using a generic rationale.

### UML and topology
- Requirement-derived sequence interactions now use component-specific actions instead of repeated generic "invoke/read/publish" messages.
- Architecture connectors use directional orthogonal routing based on source/target geometry.
- Digital Twin topology visualizes the same generated architecture with runtime simulation state.

### Reports
- PDF report includes competitive debate and Digital Twin capability description.

## Validation
- AI service source compiles with Python syntax checks.
- Existing AI test suite: 13 passed with `PYTHONPATH=.`.
- Digital Twin smoke test: scenario generation + simulation passed.
- Backend/Frontend full builds require the user's normal Maven/Eclipse and npm environments; this container does not contain Maven and could not complete `npm ci` within the available execution window.
