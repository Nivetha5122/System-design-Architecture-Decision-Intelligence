# ARCHDS V8.1 Final Fixes

This build is based on the uploaded ARCHDS V8.0 project and focuses on the requested production fixes:

- Reworked architecture/framework connector routing to use deterministic orthogonal paths and dedicated lanes so connectors do not run through component cards.
- Reworked generated architecture SVG edges to use the same routed paths used by the interactive view.
- Improved requirement-derived UML rendering with cleaner obstacle-aware routing and clearer separation of actors, classes and sequence participants.
- Rebuilt the System Design Framework view as a requirement-derived topology with explicit component flow and evidence rather than a dense list of disconnected cards.
- Fixed PDF download handling: frontend uses a 180-second blob request, the backend explicitly requests application/pdf, validates the PDF magic header, and returns a real attachment.
- Made Digital Twin scenario selection requirement-driven: only scenarios grounded in the submitted requirement profile are surfaced, with a resilience baseline retained when necessary.
- Improved Digital Twin component-failure propagation using the actual generated candidate graph instead of assuming all components are affected.
- Reworked Delivery Lab artifacts to derive from the selected candidate and requirements, generating Terraform, Kubernetes, Docker Compose and a requirement manifest, with structural validation.
- Added responsive visual polish, subtle entrance/hover transitions, clearer cards, topology surfaces and artifact presentation.

Validation performed:
- Python syntax compilation passed.
- AI-service test suite passed: 13 tests.
- End-to-end in-process AI pipeline smoke test passed for a 20M-user banking scenario.
- Generated PDF smoke test starts with %PDF- and produced a non-empty PDF.
- Digital Twin simulation returned requirement-derived scenario results.
- Delivery Lab returned VALIDATED structural checks.
