# ARCHDS V7.2 Final Local PostgreSQL Package

## Local database
- PostgreSQL: localhost:5432
- Database: architecture_db
- User: architecture_user
- Password: host

## Start
From `archds-platform`:

```cmd
scripts\START-NO-DOCKER.cmd
```

The launcher checks TCP port 5432 using PowerShell. It does **not** require `psql.exe` to be on PATH.

## Services
- Frontend: http://localhost:5173
- Backend: http://localhost:8080
- Backend health: http://localhost:8080/actuator/health
- AI service: http://localhost:8000/health

## Database inspection
Use PostgreSQL SQL Shell if `psql` is not on CMD PATH:

```sql
\\c architecture_db
\\dt
SELECT * FROM users;
SELECT * FROM projects;
SELECT * FROM requirements;
```

## Important schema fixes
V7.2 is compatible with the existing database schema reported by the previous run:
- legacy NULL requirement iteration/alternative values are accepted;
- verification JSON uses TEXT instead of PostgreSQL OID LOB mapping;
- user `updated_at` is populated automatically.
