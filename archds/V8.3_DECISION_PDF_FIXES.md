# ARCHDS V8.3 — Decision + PDF Reliability Fixes

- Normalized architecture candidate identifiers in the React dashboard (`candidate_id`, `candidateKey`, `candidate_key`, or persisted numeric `id`).
- Final Decision now always sends a concrete candidate identifier and the backend accepts either the generated candidate key or persisted candidate ID.
- Decision validation gives a clear error only when the candidate truly does not exist or belongs to another project.
- PDF generation now uses a dedicated 45-second AI report timeout instead of waiting for the general AI timeout.
- If the AI report renderer is unavailable or returns a non-PDF response, Spring Boot returns a valid fallback PDF containing the project and selected architecture instead of leaving the browser stuck.
- Frontend PDF timeout reduced to 60 seconds and retains PDF signature validation.
- AI PDF helper also accepts Pydantic model objects when used directly.
- AI tests: 13/13 passed; Python compilation passed.
