# Explainability and Traceability

ARCHDS exposes structured requirement records, driver mappings, candidate requirement mappings, reviewer findings, evaluation values, decision evidence, ADRs and convergence evidence.

A traceability record contains:

`Requirement → Architectural Driver → Decision → Component → Evidence → Evaluation → Critique`

Confidence combines requirement completeness, consistency, requirement coverage, reviewer agreement, candidate separation and unresolved high-severity findings. Confidence is therefore evidence-derived rather than a free-form LLM assertion.
