# AI Workflow

Requirements → clarification → architectural drivers → architecture knowledge retrieval → candidate generation → independent security/scalability/reliability/cost review → consistency verification → weighted multi-objective evaluation → Pareto analysis → targeted refinement → re-evaluation → convergence detection → architecture judge → explanation → diagram graph → requirement traceability.

The default provider is deterministic so a complete demonstration works without an external API key. The provider abstraction remains available for OpenAI-compatible endpoints. Structured Pydantic validation prevents malformed model output from entering the pipeline.
