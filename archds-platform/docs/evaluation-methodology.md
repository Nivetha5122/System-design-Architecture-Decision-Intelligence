# Evaluation Methodology

ARCHDS reports: requirement coverage, architecture readiness, weighted quality, Pareto frontier size, critical findings, convergence iteration, refinement improvement, candidate diversity, reviewer agreement and runtime.

Ablation conditions should compare the full pipeline with critics removed, refinement removed and Pareto optimization removed. The same input requirements and priority weights should be used across conditions. Report mean and variance over repeated runs when stochastic providers are enabled.
